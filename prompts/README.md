# Prompt log

Create one file per user prompt: `YYYY-MM-DD-NNN-short-topic.md`, numbered in order for the user's local date. Keep the original request under **Prompt** (with secrets redacted), then update the work summary as the request progresses. Do not overwrite earlier entries.

```markdown
# YYYY-MM-DD — Short topic

## Prompt

> User's request

## Questions and decisions

- Questions asked, answers received, and decisions made.

## Actions

- Investigation and work performed.

## Files changed

- Paths and brief reasons, or "None."

## Verification

- Checks and results, or "Not run" with a reason.

## Outcome

- Completed work, open items, and next step.
```
